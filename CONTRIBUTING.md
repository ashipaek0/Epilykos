# Contributing

## Commits and pull requests

- Every commit and pull request is authored by **ashipaek0** (`ashipaek0 <folabiklan@gmail.com>`):
  `git config user.name ashipaek0 && git config user.email folabiklan@gmail.com`
- No tool or assistant attribution anywhere: no co-author or session trailers in commit
  messages, and no "generated with" footers or links in pull request titles, bodies or comments.
- Branch names describe the change (`fix/…`, `feat/…`, `chore/…`), never a tool.
- Keep pull requests short:
  - what changed, in a line or two
  - the bug, if it fixes one
  - the files edited or added
  - the reason, if it isn't obvious
