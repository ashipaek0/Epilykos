Controls

Change inverter and battery settings. Every change is checked, read back and written to the change log.

Changes are locked

Enter your password to unlock changes for a few minutes. Reading values doesn't need it.

Safety switches

Allow device changes

Off: nothing on this page or the dashboard can change an inverter or battery setting.

Expert register writes

Writes to any register number, outside a device's list of settings. Only for registers you have checked in your device's manual.

Switches and selectors

Edit in layout editor

Lay these out in the layout editor: pick Controls page from its dashboard menu. They only appear here.

Device settings

Each change reads the setting first, checks the new value against its range, and reads it back afterwards.

Expert register writes

Register numbers in decimal or hex (0x…), values as whole numbers 0–65535 in raw register units (no scaling).
