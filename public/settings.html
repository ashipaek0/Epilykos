Help

Setup guide & troubleshooting

Start in Data Sources — add Home Assistant, MQTT, Modbus, Dongle, BMS, or REST API. Map entities/topics/registers to metric names.

Metric names identify your data. Common names: solar consumption battery_soc grid_import. Binary sensors auto-convert to 1/0.

Use the Editor for visual drag-and-drop layout. Each block has a Config button to pick which metrics feed it.

Enable, enter lat/lng and kWp. Add Solcast API key for high accuracy, or leave blank for free Open-Meteo.

Dashboard → Display: background colours, background image, transparent blocks, title, logo, favicon.

Dongle timeout: check IP reachable. Connection refused: port not open. Checksum mismatch: wrong serial number or profile. No data: check metric names match. Debug logs at logs/energy-dashboard-*.log. Set LOG_LEVEL=debug for verbose output.
