Data source guides
Home Assistant

Reads sensor values from Home Assistant over HTTP.

Required URL, e.g. http://192.168.1.50:8123
Required Long-lived token (Profile → Security)
  1. Sources → Home Assistant: enter the URL and token, press Fetch Entities
  2. + Add Metric Mapping: pick a metric name and an entity
  3. Set the poll interval (30 to 60 s)

MQTT

Subscribes to topics on any broker.

Required Broker URL, e.g. mqtt://192.168.1.50:1883
Optional Username and password
  1. Sources → MQTT: enter the URL, press Test Broker
  2. Discover Topics, or type one
  3. + Add Metric Mapping: pick a metric name and a topic

Metric names and roles
  • Lowercase with underscores: battery_voltage
  • Descriptive: pv1_power, not solar
  • Consistent suffixes: _power, _voltage, _current, _energy, _soc, _temp

Prices and savings

Prices are per kWh, set in Prices and savings. Each day's saving is that day's solar kWh × a price, and Solar savings picks the price:

ChoicePrice per solar kWhExample (4 kWh solar, grid 0.30, generator 0.50)
At the grid buy price (default)Grid price4 × 0.30 = 1.20
By grid availabilityGrid price, or generator price during outages. Needs the grid status metric.Half in an outage: 4 × (0.5 × 0.30 + 0.5 × 0.50) = 1.60
By what you actually boughtThe day's average of the grid and generator prices you paidBought 2 kWh grid, 3 kWh generator: 4 × (2 × 0.30 + 3 × 0.50) ÷ 5 = 1.68

Set a generator price first, or outage solar counts as worth nothing.
