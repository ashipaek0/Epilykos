## Technical Constraints

1. **No frontend framework** — vanilla JS only. No React/Vue.
2. **Settings has its own CSS** — embedded in `<style>` inside `settings.html`. Keep it there or extract shared parts to `style.css`.
3. **CSS custom properties** for theming (`--bg`, `--card-bg`, `--text`, `--accent`, etc.) — dark/light via `[data-theme="dark"]`
4. **Device config forms** generated by JS functions: `buildHaDeviceList()`, `buildMqttDeviceList()`, `buildModbusDeviceList()`, `buildExternalSourceList()`, `buildBmsDeviceList()`, `buildDongleDeviceList()` in `settings.js`
5. **Nested form naming** — `ha_devices[${idx}][name]` — server receives arrays
6. **Chart.js 4.4.0** via CDN for charts
7. **Gridstack 12.6** for drag/resize dashboard layout
8. **SQLite** via `better-sqlite3` — no migration needed for CSS/HTML changes
