1844| Troubleshooting — common issues and solutions 1845|
1846|

Device not showing data: Check physical connections, verify the correct profile is selected, and ensure the poll interval is reasonable.

1847|

PVOutput upload failing: Verify API key and System ID. Check timezone is correct. Use the Test Connection button.

1848|

Forecast not loading: Ensure latitude/longitude are set correctly and the Solcast API key is valid (free tier: 10 calls/day).
